## Gotchas already paid for

- **Overlay scrollbars** cover content and widen on hover (macOS). Standard
  `scrollbar-width`/`scrollbar-color` did **not** help (measured 0 px);
  `::-webkit-scrollbar` styling gives 10 px of real space. Setting the standard
  properties on an element disables `::-webkit-scrollbar` in Chromium, so only
  Firefox gets them (`@supports not selector(::-webkit-scrollbar)`).
- **Tailwind arbitrary vars**: `text-(--x)` / `border-(--x)` are ambiguous; use
  `text-(color:--x)`, `border-(color:--x)`.
- **Coverage pane `mix-blend-mode: multiply`** sinks colours to black on a dark
  map; overridden in dark mode (`surveillance-map.module.css`, `!important`
  because it is inline).
- **Map labels** were hard-coded dark with a white halo; now
  `--map-label`/`--map-halo` per theme.
- **Sticky table cells** paint `bg-card`; a tinted header needs `[&_th]:bg-…` on
  the thead to cover the pinned column.
- **JSX `cond && (<>…</>)`**: a comment beside the element inside `&& (` is a
  syntax error; and python splices of prettier-formatted JSX failed several
  times. Re-read the file after prettier before editing.
- **Default filters hide most Programs**: Surveillance-only + last month shows
  only Uganda (other Programs had 0 records in Sep 2026). With all types,
  Jan–Sep: Ghana 617 GPS points, Kenya 282, Colombia 51.
- Site geocoding (Nominatim, 1/s, background) resolves all 18 unplaced
  non-Uganda Sites; the panel stays in "loading" until it finishes.
