## What exists

Single-page Next 16 dashboard (App Router, Cache Components) for VectorCam
developers, across every Program. Stack: TanStack Query, nuqs, Zod 4, next-intl
(English), shadcn copied from VectorVerify, react-leaflet +
react-leaflet-cluster, recharts, exceljs (server), Vitest. Package manager:
**yarn**.

Page, top to bottom:

- **Toolbar**: Program filter (URL `exclude`, default `[5]`) with Select all /
  Deselect all; one Reporting Period (`range`, default last-month). Programs are
  shown **country first, name below** everywhere (`ProgramLabel`), or one-line
  "Uganda (National Malaria Elimination Division)" (`programTitle`).
- **Map** (`map-section.tsx`):
    - **Map filters** popover (replaces the old layer switch). URL params:
      `layers`, `hideSpecies` (default `none`), `hideSex`, `hideAbdomen`,
      `nonMosquito` (false), `zeroCatch` (false), `deviceStatus` (`ACTIVE`).
      Lists hold _hidden_ values so new ones appear automatically. Map only; the
      KPI tiles and tables ignore them.
    - "Not on the map" notice names each selected Program with nothing shown and
      why, with Show everything.
    - Every click opens a themed popup: point → Session/device details +
      specimen summary; cluster → summary + Zoom in, or Spread out when points
      share a spot. Device popups summarise everything the device submitted,
      ignoring filters; specimen summaries name the filters hiding the rest.
    - Side panel: chart of the selection or the whole map, stacked by Species /
      Sex / Abdomen. **Temporary view switch: Pie (default) | Stacked | Lines |
      Totals** so the user can pick. Readouts live in the legend or donut
      centre; no floating tooltips (they covered the chart). Bars are week (≤3
      months), month (≤24) or quarter; leading empty buckets trimmed.
    - Device lists below (without a location, never used), sticky headers.
- **Summary**: KPI tiles, Programs × metrics table (country is the Session panel
  link), Copy for Excel.
- **Session panel** (URL `sessions`): Site names with ids, every column sorts
  (asc → desc → default), State/Device/Site/Missing filter with counts, fixed
  "Showing X of Y" row, sheet up to 96vw.
- **VectorVerify users**: numbered Users table and Logins by month, both with a
  sticky Total row; empty month runs fold ("Apr–Jun 26"); .xlsx report.
- **Loading**: skeleton mirrors the page layout; message is screen-reader only.

## Gotchas already paid for

- **Sticky table headers** only stick if the `Table`'s own container scrolls:
  pass `containerClassName="max-h-… overflow-auto"`, not overflow on a parent.
  Sticky footers need `[&_td]:bg-card` and `-bottom-px`, or rows show through.
- **Popovers inside a Sheet/Dialog** won't scroll (Radix scroll lock): pass
  `container` to `PopoverContent` (added today) pointing inside the sheet.
- **react-leaflet position props** must be stable arrays (memoised); a new array
  per render re-adds the marker and collapses a spiderfied cluster.
- Cluster clicks don't zoom (`zoomToBoundsOnClick={false}`); the popup button
  zooms or spiderfies. `_group._spiderfied` tells whether it's spread.
- React compiler lint: never read `ref.current` during render, not even by
  passing it to a helper; read it inside an inline event handler.
- Recharts tooltips and a narrow panel don't mix; use the legend/centre readout.
  Chart colours use `--series-*` (validated with the dataviz skill's script).
- Leaflet's CSS loads after ours: scope overrides under `.leaflet-container`.
- Radio-like `ToggleGroup` items are `role="radio"`; popovers are
  `role="dialog"`, so select the sheet by `[data-slot="sheet-content"]` in
  scripts.
- The auto-mode safety check once blocked a read after a memory edit; the user
  approved continuing. If it happens, explain plainly and ask.
