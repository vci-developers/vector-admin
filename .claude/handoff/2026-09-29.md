## What exists

A single-page Next 16 dashboard (App Router, Cache Components on) for
VectorCam developers (`isDeveloper`) that reports on every Program at once.
The stack is TanStack Query, nuqs, Zod 4, next-intl (English only), shadcn
components copied from VectorVerify, react-leaflet with react-leaflet-cluster,
exceljs (server only) and Vitest. Package manager: **yarn**.

Page, top to bottom:

- **Toolbar**: Program filter (URL `exclude`, default `[5]`) and **one**
  Reporting Period (`range` = last-month (default) | 3m | 6m | 12m | ytd | all
  | custom, plus `from`/`to`). There is deliberately no other time control;
  the user rejected having several.
- **Map**: specimens and devices shown together (`layers`, both on by
  default, at least one always on).
  - Specimen circles use a red severity scale by specimen count per Session.
  - Devices are rounded-square badges, green for active and grey otherwise,
    offset up and to the right so they don't hide the specimen circle.
  - Placement order: GPS (latest in-country fix) → Site geocoded with
    Nominatim (dashed outline, labelled "Site location (no GPS)") → listed as
    "without a location" with a reason.
- **Summary** for the period:
  - KPI tiles comparing with the same-length period before;
  - a Programs × metrics table with expandable Field Completeness and a
    compact cycle note;
  - Copy for Excel (TSV);
  - a Session panel opened by clicking a Program name (URL `sessions`).
- **VectorVerify users**: a Users table, a Logins by day (one month) or by
  month table, and an .xlsx download built in the BFF (the backend report
  can't honour the Program filter).

## Data flow

- `src/api/admin/admin-client.ts`: the admin-token client can **only** send
  GETs, and only to the allowlisted endpoints (`/programs`, `/sessions/`,
  `/specimens/`, `/devices/`, `/sites/`, `/users/auth-events`,
  `/programs/{id}/collection-cycles`). Pages are fetched 5 at a time.
- `src/api/admin/load-program-snapshot.ts`: one snapshot per Program, cached
  with `'use cache'` for an hour and served stale while it refreshes (`cacheLife('hours')`).
  A failed load is cached only for seconds. Concurrent callers share one
  in-flight load, because `'use cache'` does not merge them and a duplicated
  cold load once failed Uganda. `POST /api/refresh` drops the cache via tags.
- Pure, tested metric code lives in `src/features/dashboard/utils/`:
  `build-period-metrics`, `classify-devices`, `build-specimen-points`,
  `build-program-sessions`, `build-user-logins`, `place-by-site`,
  `site-location-query`, `summary-rows`, `resolve-reporting-range`,
  `specimen-severity`, `cycle-label`.
- BFF routes (each wrapped in `withViewer`, which checks `devMode` from
  `/users/permissions`):
  - `/api/dashboard`
  - `/api/program-sessions`
  - `/api/user-logins` and `/api/user-logins/report`
  - `/api/site-locations`
  - `/api/refresh`
  - `/api/auth/login` and `/api/auth/logout`
- `src/api/geocode/`: a process-wide background Nominatim geocoder (one
  request per second, in-memory cache, retries errors, rejects matches outside
  the Program's country). The client polls `/api/site-locations` every 3 s
  while any Sites are pending.

## Gotchas already paid for

- Anything that imports `leaflet` must only be loaded through
  `next/dynamic({ ssr: false })`. Shared constants live in `map-constants.ts`
  so the server render never pulls Leaflet in.
- The map card uses `isolate`, which keeps Leaflet's z-indexes (400+) below
  popovers, the sheet and the sticky toolbar.
- Clustering never switches off. `maxClusterRadius` shrinks but never reaches
  zero, so points sharing a GPS fix fan out when clicked.
- Leaflet `divIcon` inline styles keep their raw text (`border-radius:6px`,
  no space); match that in selectors.
- The React compiler lint forbids reading `ref.current` during render. Pass
  callbacks that capture the ref instead.
- Cache Components: `cookies()` must sit behind `<Suspense>`
  (`features/auth/components/viewer-gate.tsx`).
- After renaming a route, `.next/types` goes stale and typecheck fails until
  `yarn build` regenerates it.
- Prettier's `proseWrap: always` also rewraps `.claude/*.md`.
- Test API facts:
  - Program ids 7–14. Program 5 is prod Johns Hopkins University, hidden by
    default.
  - Login tracking starts 2026-06-26. Months before that show blank user
    counts, not zero.
  - Session 1408 has null `collectionDate` and `createdAt`.
  - Most Session GPS is outside the country (recorded at upload), which is
    why the Site fallback exists.

   fix is backend aggregate endpoints (ADR-0001); the user expects that
   backend change.

   snapshot, so showing names is a small change.
7. **More than eight Programs**: any past the eighth share a grey colour for
   their dots.
